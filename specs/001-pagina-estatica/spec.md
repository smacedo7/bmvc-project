# Nível 1 — Página estática BMVC

## História
Como avaliador, quero abrir uma página própria do projeto, entender sua finalidade e ver CSS e JavaScript em funcionamento.

## Critérios de aceitação
- Executar `python route.py` e abrir `/` localmente.
- A página HTML/TPL descreve o ERP/CRM e seus quatro módulos em texto legível.
- O CSS externo define a apresentação e o layout responsivo.
- O JavaScript externo filtra os módulos ao digitar; a contagem e a mensagem de busca vazia mudam sem recarregar.
- A página é diferente do `helper.tpl` do BMVC usado em sala.
- O vídeo de até 3 minutos mostra a execução local, os arquivos CSS/JS ativos e o repositório público.
